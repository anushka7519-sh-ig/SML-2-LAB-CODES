
## Module 1 — Overview of Machine Learning Techniques

All labs below use the **BSDS500** image dataset (`images/train`, `images/test`, `images/val`) in place of the dataset named in the official list.

| Lab # | File (in `notebooks/`) | Task | Dataset used |
|---|---|---|---|
| 1 | `knn_from_scratch.ipynb` | k-NN classifier implemented from scratch | BSDS500 (image features) |
| 2 | `decision_tree.ipynb` | Decision Tree classifier (scikit-learn) with tree visualization | BSDS500 (image features) |
| 3 | `gaussian_naive_bayes.ipynb` | Gaussian Naive Bayes classifier | BSDS500 (image features) |
| 4 | `logistic_regression.ipynb` | Logistic Regression from scratch using gradient descent | BSDS500 (image features) |
| 5 | `pca_tsne.ipynb` | PCA and t-SNE for dimensionality reduction to 2D, cluster visualization (via K-Means) | BSDS500 (flattened image vectors) |
| 6 | `outlier_detection.ipynb` | Outlier detection and treatment using Z-score and IQR methods | BSDS500 (image-level intensity features) |
| 7 | `sml_lab_7.ipynb` | Comparison of Accuracy, Precision, Recall, F1-score, and ROC-AUC for Logistic Regression vs SVM | BSDS500 |

> **Note on Lab 5:** originally written as a standalone script (`Q5_1.py`); convert/save as `pca_tsne.ipynb` before adding to `notebooks/` to keep the folder notebook-only.
